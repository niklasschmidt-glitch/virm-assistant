# Installation af VIRM Assistant i Safari

VIRM Assistant til Safari udgives som et userscript. Du skal derfor først installere den gratis **Userscripts**-app:

**[Hent Userscripts til iPhone, iPad eller Mac](https://apps.apple.com/app/userscripts/id1463298887)**

Vælg derefter den udgave, der passer til din enhed:

- **[Safari på iPhone/iPad – installationsfil](https://raw.githubusercontent.com/niklasschmidt-glitch/virm-assistant/main/safari/VIRM_Assistant_Safari_Mobile.user.js)**
- **[Safari på Mac – installationsfil](https://github.com/niklasschmidt-glitch/virm-assistant/releases/latest/download/VIRM_Assistant_Safari_Computer.user.js)**

## iPhone og iPad

1. Installér **Userscripts** fra linket ovenfor.
2. Åbn Userscripts én gang, og vælg eller bekræft den mappe, hvor scripts gemmes.
3. Åbn **Indstillinger > Apps > Safari > Udvidelser > Userscripts**, og slå udvidelsen til.
4. Giv Userscripts adgang til `virtualmanager.com`. Scriptet er teknisk begrænset til Virtual Managers sider.
5. Åbn linket **Safari på iPhone/iPad – installationsfil** i Safari.
6. Åbn Userscripts via Safaris udvidelsesmenu, og godkend installationen af VIRM Assistant.
7. Genindlæs Virtual Manager.

Hvis installationsvinduet ikke vises, kan du i stedet gemme `.user.js`-filen i den scriptmappe, som er valgt i Userscripts.

## Mac

1. Installér **Userscripts** fra linket ovenfor.
2. Åbn **Safari > Indstillinger > Udvidelser**, og slå Userscripts til.
3. Giv Userscripts adgang til `virtualmanager.com`.
4. Åbn linket **Safari på Mac – installationsfil** i Safari.
5. Åbn Userscripts via Safaris værktøjslinje, og godkend installationen.
6. Genindlæs Virtual Manager.

Hvis installationsvinduet ikke vises, kan `.user.js`-filen downloades og tilføjes manuelt i Userscripts.

## Opdateringer

VIRM Assistant indeholder oplysninger om den seneste download. Når en nyere version udgives, kan Userscripts kontrollere versionsnummeret og hente opdateringen. Du kan også altid hente den nyeste udgave via linksene på denne side.

## Om projektet

VIRM Assistant er udviklet uafhængigt og er ikke tilknyttet, godkendt eller understøttet af udviklerne bag Virtual Manager eller Userscripts.
