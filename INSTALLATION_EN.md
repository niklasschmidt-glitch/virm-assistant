# Installing VIRM Assistant in Safari

VIRM Assistant for Safari is distributed as a userscript. You must therefore first install the free **Userscripts** app:

**[Download Userscripts for iPhone, iPad, or Mac](https://apps.apple.com/app/userscripts/id1463298887)**

Then choose the version for your device:

- **[Safari on iPhone/iPad – installation file](https://raw.githubusercontent.com/niklasschmidt-glitch/virm-assistant/main/safari/VIRM_Assistant_Safari_Mobile.user.js)**
- **[Safari on Mac – installation file](https://github.com/niklasschmidt-glitch/virm-assistant/releases/latest/download/VIRM_Assistant_Safari_Computer.user.js)**

## iPhone and iPad

1. Install **Userscripts** using the link above.
2. Open Userscripts once, then select or confirm the folder where scripts will be stored.
3. Open **Settings > Apps > Safari > Extensions > Userscripts**, then enable the extension.
4. Allow Userscripts to access `virtualmanager.com`. The script is technically restricted to Virtual Manager pages.
5. Open the **Safari on iPhone/iPad – installation file** link in Safari.
6. Open Userscripts from Safari’s extensions menu and approve the installation of VIRM Assistant.
7. Reload Virtual Manager.

If the installation window does not appear, you can save the `.user.js` file in the scripts folder selected in Userscripts instead.

## Mac

1. Install **Userscripts** using the link above.
2. Open **Safari > Settings > Extensions**, then enable Userscripts.
3. Allow Userscripts to access `virtualmanager.com`.
4. Open the **Safari on Mac – installation file** link in Safari.
5. Open Userscripts from Safari’s toolbar and approve the installation.
6. Reload Virtual Manager.

If the installation window does not appear, you can download the `.user.js` file and add it to Userscripts manually.

## Updates

VIRM Assistant includes information about the latest download. When a newer version is released, Userscripts can check the version number and download the update. You can also always download the latest version using the links on this page.
