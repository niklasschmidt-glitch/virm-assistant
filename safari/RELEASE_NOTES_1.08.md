# VIRM Assistant 1.08 – Safari for Mac and mobile

Both Safari editions are updated to 1.08 with the current tools from the Chrome edition.

- A customizable Control center with training, contracts, matches, stadiums, league tables and notes.
- Contract renewal for senior players, youth players and employees.
- Current fixes for player forecasts, language selection and youth players, plus VMAN's Train now button in Control center.
- All 14 Danish and English PDF manuals are included.
- Anonymous activity statistics are retained. Public builds include no debug or admin panels.
- Stable installation and update URLs are retained for both Safari editions.

Checked locally for JavaScript syntax, version numbers, source and resource parity, storage and anonymous activity signals. Physical Mac/Safari and iPhone testing was not performed in this session.
